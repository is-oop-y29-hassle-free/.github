# Лабораторная 2

## Отрабатываемый материал

Порождающие паттерны: фабрика (абстрактная фабрика), строитель, прототип.  

## Цель

Научиться отделять логику создания объектов от логики их использования, применить на практике паттерны фабрика, строитель и прототип.  

## Задание

- Реализовать объектную модель планетарной колонии: создание зданий, сборку колонии, копирование колонии и расчёт её производства  
- Покрыть полученное решение модульными тестами (xUnit)  

## Формулировка

Компания «Moon Mining Inc.» открывает новое направление – планетарное производство. На планете строится колония:  
командный центр, экстракторы, добывающие сырьё, и фабрики, перерабатывающие сырьё в товары.  

Все здания колонии должны соответствовать типу планеты: на лавовой планете строятся только лавовые здания.  
Мощности командного центра ограничены, поэтому не каждый набор зданий можно построить.   
Удачную колонию компания хочет тиражировать на другие планеты того же типа.  

Вам нужно разработать модель, которая создаёт здания, собирает из них колонию, копирует колонию на другие планеты и рассчитывает производство колонии за заданное время.

## Предметная область

### Планеты и сырьё

Планета характеризуется названием и типом. Тип планеты определяет, какое сырьё на ней можно добывать, и сколько единиц сырья в час добывает один worker экстрактора.

| Тип планеты | Сырьё и добыча одного worker'а, ед./ч                          |
|-------------|--------------------------------------------------------------|
| Barren      | Base Metals – 1500, Noble Metals – 1500, Microorganisms – 1000 |
| Temperate   | Microorganisms – 1500, Autotrophs – 1500, Complex Organisms – 1000 |
| Lava        | Base Metals – 1000, Heavy Metals – 1500, Felsic Magma – 1500   |

### Товары и рецепты

Сырьё (P0) перерабатывается в товары первого уровня (P1), товары первого уровня – в товары второго уровня (P2).  

Рецепты переработки P0 → P1 (базовая фабрика, за 1 ч: 6000 ед. сырья → 40 ед. товара):  

| Сырьё             | Товар P1          |
|-------------------|-------------------|
| Base Metals       | Reactive Metals   |
| Noble Metals      | Precious Metals   |
| Microorganisms    | Bacteria          |
| Autotrophs        | Industrial Fibers |
| Complex Organisms | Proteins          |
| Heavy Metals      | Toxic Metals      |
| Felsic Magma      | Silicon           |

Рецепты переработки P1 → P2 (продвинутая фабрика, за 1 ч: по 40 ед. каждого из двух товаров → 5 ед. товара):   

| Товар P2             | Входные товары                     |
|----------------------|------------------------------------|
| Mechanical Parts     | Precious Metals + Reactive Metals  |
| Nanites              | Reactive Metals + Bacteria         |
| Fertilizer           | Proteins + Bacteria                |
| Construction Blocks  | Toxic Metals + Reactive Metals     |
| Microfiber Shielding | Silicon + Industrial Fibers        |

Все рецепты образуют каталог рецептов.  

### Здания

Каждое здание принадлежит типу планеты и потребляет мощности командного центра
 - процессор (CPU, измеряется в tf (терафлопс))
 - энергию (PowerGrid (сокр. PG), измеряется в MW (мегаватт))

| Здание                | CPU, tf          | PG, MW            | Параметры                                         |
|-----------------------|------------------|-------------------|---------------------------------------------------|
| Командный центр       | –                | –                 | уровень 0–5, предоставляет мощности (см. ниже)    |
| Экстрактор            | 400 + 110 × N    | 2600 + 550 × N    | добываемое сырьё, число worker'ов N (1–10)          |
| Базовая фабрика       | 200              | 800               | рецепт P0 → P1                                    |
| Продвинутая фабрика   | 500              | 700               | рецепт P1 → P2                                    |

Мощности командного центра:  

| Уровень | CPU, tf | PG, MW |
|---------|---------|--------|
| 0       | 1675    | 6000   |
| 1       | 7057    | 9000   |
| 2       | 12136   | 12000  |
| 3       | 17215   | 15000  |
| 4       | 21315   | 17000  |
| 5       | 25415   | 19000  |

Экстрактор может добывать только сырьё, которое есть на планете его типа.  

### Колония

Колония – это планета, командный центр и упорядоченный набор остальных зданий. Колония построена корректно, если:

1. все здания, включая командный центр, принадлежат типу планеты колонии
2. суммарное CPU зданий не превышает CPU командного центра
3. суммарная PG зданий не превышает PG командного центра

Колонию можно скопировать на другую планету **того же типа**:  
копия содержит копии всех зданий в том же порядке.  
Скопировать колонию на планету другого типа нельзя.  

## Требования к созданию объектов

Согласно этим требованиям у вас должно появится понимание какой паттерн использовать для решения данной проблематики.

- Для каждого типа планеты есть объект, который создаёт **семейство** зданий этого типа: командный центр, экстрактор, базовую и продвинутую фабрики.
- Код, собирающий колонию, получает фабрику через абстракцию и не знает её конкретного типа.
- Добавление нового типа планеты не требует изменения существующих классов.
- Фабричный метод (наследование ради создания объектов) не используется.
- Колония должна создаваться пошагово. Создать колонию напрямую через конструктор должно быть невозможно.
- Условия корректности колонии должны проверятся при сборке.
- Планету и командный центр нельзя не указать: без вызова этих шагов сборка решения не должно компилироваться.
- Каждое здание поддерживает копирование. Копия имеет тот же конкретный тип, что и оригинал: получение копии не требует приведения типов.
- Колония копируется на другую планету через копирование своих зданий, не зная их конкретных типов.
- Каталог рецептов передаётся тем, кому он нужен, через конструктор. Статические глобальные экземпляры не используются.

## Расчёт производства

Производство колонии рассчитывается за целое число часов N > 0. У колонии общий склад, изначально пустой.  
Каждый час выполняется по шагам:  

1. Каждый экстрактор добавляет на склад `число worker'ов * добыча одного worker'а` единиц своего сырья.
2. Каждая базовая фабрика по порядку в колонии: если на складе есть 6000 ед. её сырья, забирает их и добавляет на склад 40 ед. товара. Иначе простаивает.
3. Каждая продвинутая фабрика по порядку в колонии: если на складе есть по 40 ед. каждого входного товара, забирает их и добавляет на склад 5 ед. товара. Иначе простаивает.

Товары, произведённые на шаге, доступны следующим шагам того же часа. Все величины – целые числа.

Результат расчёта - количество каждого сырья и товара на складе после N часов.

## Исключения и результат

| Ситуация                                                                                                   | Как сообщается                      |
|------------------------------------------------------------------------------------------------------------|-------------------------------------|
| Некорректные данные при создании объекта: уровень командного центра вне 0–5, число worker'ов вне 1–10, сырьё, которого нет на планете, N ≤ 0 | исключение (`ArgumentException`)    |
| Колония не собрана: здание другого типа планеты, превышение CPU или PG                                     | результат-неудача с причиной        |
| Копирование колонии на планету другого типа                                                                | результат-неудача с причиной        |
| Фабрика простаивает из-за нехватки сырья или товаров                                                        | обычная часть результата расчёта    |

## Тестовые сценарии

Колония «Mechanical Parts» (используется в нескольких сценариях) – планета Barren-I типа Barren; здания создаются
фабрикой Barren в таком порядке:

1. экстрактор Noble Metals, 4 worker'а
2. экстрактор Base Metals, 4 worker'а
3. базовая фабрика Noble Metals → Precious Metals
4. базовая фабрика Base Metals → Reactive Metals
5. продвинутая фабрика Mechanical Parts

Сценарии не покрывают все правила – остальные тесты составьте самостоятельно.

### Сценарий 1. Сборка колонии

Колония «Mechanical Parts» с командным центром уровня 2.

Результат: колония собрана. CPU 2580 из 12136, PG 11900 из 12000.

### Сценарий 2. Нехватка энергии

Колония «Mechanical Parts» с командным центром уровня 1.

Результат: колония не собрана – PG 11900 превышает 9000.

### Сценарий 3. Здание другого типа планеты

Колония «Mechanical Parts» с командным центром уровня 2, в которой базовая фабрика Base Metals создана на планете типа Lava.

Результат: колония не собрана – здание не соответствует типу планеты.

### Сценарий 4. Сырьё не с этой планеты

Создание на планете типа Lava экстрактора Noble Metals.

Результат: исключение.

### Сценарий 5. Производство за сутки

Колония из сценария 1, N = 24.

Результат: Mechanical Parts – 120, остальных сырья и товаров на складе – 0.

### Сценарий 6. Копирование колонии

Колония из сценария 1 копируется на планету Barren-II и на планету Lava-I.

Результат:

- на Barren-II – копия создана; её производство за 24 ч совпадает со предыдущим сценарием
- на Lava-I – копия не создана: тип планеты отличается
